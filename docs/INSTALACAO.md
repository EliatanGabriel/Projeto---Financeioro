# Instalação

## No navegador
```bash
npm install
npm run dev    # http://localhost:5173
```

## No Windows (app de desktop)
Instale o Tauri bundle (.msi/.exe) quando disponível. Abra, cadastre seus movimentos,
contas fixas e metas. Para o Pro, ative na tela Pro com a chave da assinatura Cakto.

Backup: Ajustes > Baixar cópia / Restaurar cópia.
